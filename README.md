# 漫镜 Manjing

> 面向 AI 漫剧、AI 短剧与系列视频制作的 Windows 桌面工作台。

![漫镜工作台总览](README-media/漫镜视觉-01.png)

漫镜把剧本、Agent 团队、长期记忆、技能、角色与场景资产、分镜、视频、配音和剪辑放进同一个项目。用户可以导入整部系列剧本，选择具体剧集制作，并让各岗位 Agent 在项目记忆和 Canonical 标准资产的约束下协同工作。

## 主要功能

### Agent 创作团队

- 总制片、导演、编剧、分镜、镜头总控、生图、视频、配音和剪辑 Agent。
- 每个 Agent 拥有独立聊天、长期记忆和可编辑 Skill。
- 内置 188 个岗位 Skill，并支持导入 `.skill`、`.md`、`.txt`、`.json`、`.yaml`、`.docx` 和 `.pdf`。
- 总制片可以将规则、记忆和技能派送给对应岗位。

![Agent 与创作工作区](README-media/漫镜视觉-02.png)

### 系列项目与分集制作

- 导入 40 集等长篇总剧本，自动拆分剧集、角色关系、世界规则与时间线。
- 项目、剧集、角色圣经、长期记忆和资产相互隔离。
- AI 工作台支持随时绑定或切换当前项目与剧集。
- 上一集结束状态可以传递给下一集，保持背景故事连续。

### Canonical 资产与连续性引擎

- 人物、造型、场景、道具和声音均可批准为 Canonical 标准资产。
- 已生成资产按项目和剧本语义命名，并可重复引用、重命名和批量删除。
- 人物、场景、道具、分镜和声音使用稳定复用键；状态完全一致时直接读取原资产并跳过模型调用。
- 台词完全相同时复用原音频；台词变化时仍沿用角色固定音色生成新配音。
- 镜头间传递 Start State / End State，检查人物位置、服装、道具、空间关系和光线。
- 一致性审核只检查当前景别中实际可见的内容，不再因画外场景锚点误判。
- 低于阈值时分析可见偏差并进行一次约束修复。
- 自动修复后仍未通过人物身份、演员数量、画风与空间连续性硬门槛时进入待复核；用户可按失败原因重生成、人工批准或删除候选。

![资产、分镜与视频流程](README-media/漫镜视觉-03.png)

#### 语义资产身份卡

- AI 生成资产入库时自动记录项目、实体名称、造型版本、资产类型、引用用途、识别置信度与复用范围，Agent 不再只依赖文件名猜测素材内容。
- 人物设定图分别标记脸部、正面、侧面和背面区域；近景、侧面、背影及全身镜头按用途引用对应区域。
- 场景资产标记布局、灯光、风格与空间锚点；道具资产标记外形、材质、归属和位置用途；声音资产绑定角色声音身份。
- 用户上传但尚未识别的资产标记为“待识别”，不会被 Agent 当作已确认 Canonical 资产盲目调用。
- 资产检索先按当前项目、剧集、实体、造型、场景和用途硬匹配，再进行语义相关度排序。

#### 空间状态约束与镜头衔接

- 每个镜头携带人物世界锚点、左右顺序、景深、朝向、姿态、出入画方向、道具绑定和场景固定物位置；这些是结构化提示词强约束，不能保证生成模型绝对不漂移。
- 原生视频不生成逐镜首帧图，也不把抽取的首尾帧送入模型；抽帧只用于本地质量检查。正式生成只使用当前项目的 Canonical 人物、精确造型、场景、道具、音色和可访问的已批准视频作为全能参考。
- 摄像机改变时按同一世界位置重新投影，不机械冻结屏幕坐标；同场对话遵守 180 度轴线，避免人物无理由换边。
- 提示词采用“稳定帧—单一动作—稳定帧”，减少人物和物体凭空生成、消失、复制、换手或瞬移；复杂连续动作会拆成短片段，但生成式模型仍可能出现穿帮。
- 人物身份、演员数量、画风与空间连续性均设为硬性质量门槛，不合格候选不会自动进入成片或污染下一镜参考。

### 图片、视频、声音与剪辑

- 生图 Agent 可生成人物、造型、场景、道具和分镜图。
- 新增“半写实3D国漫”风格，区分于写意国漫电影感，并对人物资产与视频统一施加非真人化风格约束。
- 镜头总控 Agent 负责绑定资产、继承镜头状态并编译 Seedance 等视频模型提示词。
- 支持火山方舟 Seedance、OpenAI 兼容接口、Pollinations、Agnes、自定义 Webhook，以及可选本地节点。
- 15 秒以内由 AI 判断是否一镜直出；长视频按剧情节奏拆镜后逐镜生成并剪辑。
- 角色声音资产可复用，配音和背景音乐分别控制。
- 独立字幕总开关同时控制预览、时间轴、编辑器交接和最终成片烧录，不影响配音、原声或背景音乐。

## v0.0.1 首个公开版本

- 人物、场景和道具在生图前都会重新检索完整资产库，命中已有图片后直接采用，不再重复调用模型。
- 旧版人物图即使没有 `sheetVersion` 元数据，只要图片存在也视为可用资产，不会被生图岗位重做。
- 支持旧文件名、人物标签、角色设定图、参考图、三视图、四视图以及历史项目资产的识别。
- 自动匹配严格限制在当前项目和公共资产库；相同人物优先使用完全一致的造型，新造型只继承已认可的身份脸，不会把其他项目素材静默串入。
- 同一项目、同一人物、同一造型只展示一张主卡；重复 AI 图保留为历史版本，用户上传或已确认资产优先。
- 重新分析剧本会保留已上传图片、资产 ID 和审核状态，不再生成第二张脸。
- Seedance 视频只使用人物、场景、道具、音色和上一镜已批准视频的全能参考；不提交首帧、尾帧图片。

## v1.5.0 性能重构

- 默认 Skill 改为浏览器空闲时异步导入，不阻塞聊天区或工作台首屏。
- Skill 与记忆数据增加内存缓存，避免每次 Agent 调用都重复解析大型本地数据。
- 顶部导航关闭重页面抢先预载，用户点击后只加载当前需要的页面代码。
- 桌面端改为单窗口客户端路由，切页不再创建第二个完整渲染器，降低内存占用并避免整页重载中断请求。
- 增加统一页面加载状态，切换过程中保持明确反馈。
- 生产进度继续使用本地运行快照保存，返回工作台后恢复当前项目和状态。

## 安装

1. 打开 [Releases](https://github.com/Laity1m/manjing-desktop/releases/latest)。
2. 下载最新的 Windows x64 `.exe` 安装包。
3. 安装并打开漫镜，在“模型中心”或 AI 工作台配置自己的模型接口。
4. 从“项目”导入总剧本，或直接进入 AI 工作台开始制作。

## Seedance 2.0 接入

- API Key：填写火山方舟 `ARK_API_KEY`。
- 模型 ID：填写已开通的 Seedance 模型或 Endpoint ID。
- 创建任务、查询任务和下载结果使用方舟原生异步接口。
- 创建请求不会盲目重试，避免重复任务和重复扣费；查询与下载支持安全重试。
- 分辨率默认使用 `720p`，并记住用户上次选择。

## 数据与隐私

- 项目、聊天、技能、记忆和资产默认保存在用户本机。
- API Key 仅用于用户主动配置的模型服务。
- Secret Key 不写入长期配置；企业资产授权由用户自己的火山账号完成。
- 第三方模型可能产生费用，请以服务商控制台和计费规则为准。

## 原生视频优先与跨镜头一致性

- Seedance、Agnes 与自定义原生视频接口不再强制先生成分镜首帧图，而是按镜头直接生成视频。
- 人物标准参考采用固定四区卡：左侧 35%–40% 为大正脸特写，右侧从上到下为正面全身、45° 侧面全身、背面全身；纯白背景、均匀平光、自然轻微 T-pose、手脚完整，目标输出为 16:9、至少 1792×1024。
- 提示词相对优先级为大头特写 1.2、三视图 1.05，服务商 guidance 建议上限 1.5；这是工作流提示权重，不代表底层引擎提供区域级硬锁。
- Canonical 身份基准只在当前生成任务内绑定；同一任务每个角色只提交一份身份基准，禁止多个历史脸图混入同一请求。每 4 镜重新挂载人物卡，每 6 镜重述一次空间基准，以减轻长序列漂移。
- 后端按正脸、侧面轮廓、背面轮廓、五官、头身比和服装一致性分别检查角色卡；极端俯仰、回头和大角度镜头仍建议补充对应角度参考。
- 模式 A（默认，身份优先）：抽取首尾帧仅用于质检，不送入生成模型；变脸风险较低，镜头衔接可能更生硬。
- 模式 B（可控继承）：允许上一镜已批准质检尾帧作为构图参考，同时把当前任务 Canonical 人物卡设为更高身份优先级；衔接更顺，但不能消除身份漂移。
- 镜头提示词强约束人物左右位置、景深、朝向、手持关系、道具归属和起止状态；重要镜头可加用户批准的构图参考图，每 6 镜重新锚定空间描述。提示词只能降低漂移概率，不能绝对锁定几何位置。
- 每个视频完成后保存中间帧和尾帧用于质检；候选必须由用户批准，批准后自动定位下一条真正缺失的镜头，也可用“继续生成第 N 镜”兜底。
- 方舟明确拒绝不可访问的视频/音频网址时，只在创建任务前去掉无效引用重试一次，保留人物、场景和道具图片，避免重复创建付费任务。
- 旁白、广告声、系统播报和画外音只进入声音流程，不生成无意义的人物信息图。

身份一致性与审美质检的设计思路参考了 [Seedream 提示词指南](https://www.volcengine.com/docs/82379/1829186)、[ConsistentID](https://arxiv.org/abs/2404.16771)、[ContextAnyone](https://arxiv.org/abs/2512.07328)、[GEN3C](https://arxiv.org/abs/2503.03751) 和 [VisionReward](https://arxiv.org/abs/2412.21059)。这些项目**没有被集成或调用**；漫镜只借鉴其细粒度身份、上下文一致性、空间连续性和多维评价思想，底层视频生成引擎仍是用户配置的火山 Seedance。

## 漫剧生产原则

漫镜把“镜头计划”“生成参考”和“长期资产”分开管理。镜头表始终保留叙事节拍、景别、机位、人物调度和 Start/End State；视觉分镜不是原生视频模型的强制前置步骤。长期资产只收录通过审核的角色身份与造型、地点布局、关键道具、角色声音和全局风格规则。普通动作帧、旁白、广告声、一次性群众和失败候选不会自动升级为 Canonical 资产。

完整流程为：项目圣经 → 剧集拆解 → 资产规划 → 镜头设计 → 镜头生产 → 连续性审核 → 声音后期 → 剪辑交付。实现参考还包括 [MovieAgent](https://github.com/showlab/MovieAgent)、[PenShot](https://github.com/neopen/story-shot-agent)、[Jellyfish](https://github.com/Forget-C/Jellyfish)、[UnityShots](https://github.com/JIA-Lab-research/UnityShots) 与 [MultiShotMaster](https://github.com/KlingAIResearch/MultiShotMaster)。

默认技能库包含用户提供的“原创AI角色捏脸提示词生成 Skill”，由生图 Agent 在首次角色建模和角色资产补跑时读取，用脸型结构、三庭五眼、五官主次、气质、妆造与光线建立原创角色身份。

### 精细化漫剧 SOP

工作台现已把人物统一、画风统一和镜头无缝衔接落实为可执行生产标准：导演 Agent 开工前建立制作圣经；镜头总控逐镜继承人物身份、造型、轴线、左右位置、手持道具、光线和动作状态；连续动作会预留镜尾与镜头开头的承接姿态；剪辑 Agent 统一分辨率、帧率、曝光、色温、响度、字幕和连续 BGM。规则不会机械限制所有镜头必须等长，镜头时长和景别仍由剧情节拍决定，单次视频生成不超过 15 秒。

工作台新增响应式“本片生产标准”控制台，集中显示当前画风、画幅、目标时长、连续性策略、配音、BGM 和字幕状态。Windows 安装版启动自检也已改为验证真实 HTML 响应，并修复生产标准面板变量错误导致的 `/studio` SSR 500 启动失败。
## 系列项目与资产联动

- 项目中心是项目数据的唯一来源，新建项目后资产库会自动生成对应的项目分组。
- 删除项目会同步清理该项目专属资产，同时保护全局公共资产，避免 Agent 误调用孤立素材。
- 资产库支持按项目展开、折叠和进入，并保持 Agent 只读取当前绑定项目及全局资产。
- 工作台完成合成后，最终视频会自动归档到项目资产和“历史成片与生成记录”。
- 项目卡片采用系列编号封面与自适应操作布局，进入项目、项目资产和删除操作层级更清晰。
