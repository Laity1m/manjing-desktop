# 漫镜 Manjing

![漫镜 AI 漫剧创作工作台](README-media/漫镜视觉-01.png)

**漫镜**是一套面向 AI 漫剧、AI 短剧和连续视频创作的 Windows 桌面工作台。它把剧本、角色、场景、道具、分镜、视频、配音、音乐、剪辑，以及可以持续学习的 Agent 团队组织在同一个本地项目中。

[下载最新版](https://github.com/Laity1m/manjing-desktop/releases/latest) · [提交问题](https://github.com/Laity1m/manjing-desktop/issues)

## 从故事到成片

![AI 工作台](README-media/漫镜视觉-02.png)

漫镜会根据目标时长分析剧本。15 秒以内优先一镜直出；超过模型单次时长限制时，由 Agent 判断镜头数量和每镜时长，再逐镜生成、检查和剪辑，而不是机械地平均切分。

- 编剧 Agent：故事、剧本、台词和结构化分镜。
- 导演 Agent：节奏、表演、镜头语言和质量复核。
- 生图 Agent：角色设定、服装造型、场景、道具和一致性关键帧。
- 视频 Agent：文生视频、图生视频、多模态参考和逐镜动态表演。
- 配音 Agent：角色声音、对白、旁白、环境音与情绪。
- 剪辑 Agent：镜头承接、字幕、音乐、音量和成片导出。
- 总制片 Agent：理解目标，向各岗位分配技能、记忆和任务。

![Agent 创作团队](README-media/漫镜-Agent团队.png)

## 可以聊天、学习和积累的 Agent

每个岗位都有独立聊天、长期记忆和技能空间。用户可以通过聊天纠正 Agent，也可以导入 Word、PDF、Markdown、TXT、Skill 等资料。总制片 Agent 负责把技能派送到合适岗位，岗位 Agent 在后续创作中自动检索和使用。

![技能与长期记忆](README-media/漫镜-技能记忆.png)

- 独立岗位聊天与会话删除。
- 可编辑长期记忆和技能。
- 内置岗位基础技能，避免 Agent 处于“婴儿状态”。
- 支持本地学习资料与 MCP 搜索结果沉淀。
- 用户可控制哪些内容进入记忆、技能或工作区。

## 系列项目与 40 集总剧本

从 `v1.4.9` 开始，一部剧对应一个独立系列项目。用户可以给项目命名并导入 DOCX、PDF、TXT、Markdown、JSON、YAML 或 Skill 格式的总剧本，漫镜会在本地完成结构化整理：

- 自动识别“第 1 集～第 40 集”等分集结构。
- 提取人物介绍、人物关系、全剧背景、世界规则和时间线。
- 建立可编辑、可锁定的项目记忆和角色圣经。
- 用户选择任意一集进入 AI 工作台制作。
- 生成时只加载本集、相关角色、项目长期记忆和上一集结束状态，避免上下文窗口溢出。
- 人物、场景、道具、视频和声音自动记录所属 `projectId/episodeId`。
- 默认只在当前项目内复用资产，用户明确共享的公共资产才会跨项目使用。
- 不同剧本互不串角色、世界观、声音和场景。

```text
系列项目
├─ 总剧本文档
├─ 第 1～40 集
├─ 角色圣经
├─ 项目长期记忆
├─ Canonical 资产
└─ 分集制作与成片
```

## Canonical 资产与一致性引擎

![资产与制作界面](README-media/漫镜视觉-03.png)

资产库不只是文件列表，而是长剧持续复用的制作标准：

- AI 按剧本中的角色、场景、道具和镜头语义命名资产。
- 角色身份、服装造型、场景、道具和声音档案可编辑、锁定和复用。
- 支持预览、重命名、分类、批量选择与批量删除。
- 可将选定版本设为 **Canonical Asset**，作为后续生成的官方标准版本。
- Agent 自动匹配并复用已生成的人物、场景、道具、视频和音频资产。
- 镜头生成后计算人物、服装、场景、道具、空间和镜头连续性评分。
- 低于质量阈值时分析失败原因并加强约束，避免直接交付错误镜头。
- 上一镜 `End State` 自动传给下一镜 `Start State`，保持人物位置、姿势、手持道具、门窗状态和光线方向连续。

## 人物声音一致性与独立音轨控制

- 音频资产可以标记“所属角色”和“声音档案”。
- 视频 Agent 会按角色复用声音资产，并作为 Seedance `reference_audio` 提交。
- 同一人物跨镜头保持音色、年龄感、语速和口音一致。
- “一键漫剧自动配音”只控制人物对白和旁白。
- 关闭人物配音后仍保留环境音和动作音效。
- 背景音乐拥有独立开关，可单独决定是否生成无歌词 BGM。

## Seedance 2.0 原生适配

漫镜使用火山方舟原生任务接口创建、查询和下载 Seedance 视频：

```text
https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks
```

- 支持 Seedance 2.0、Seedance 2.0 Fast 和 Endpoint ID。
- Seedance 2.0 Fast 自动限制为 `480p/720p`，避免无效的 `1080p` 请求。
- 创建请求最长等待 180 秒，连接中断时不盲目重提，避免重复创建和扣费。
- 保存漫镜请求编号与方舟任务编号，任务查询和视频下载可恢复重试。
- 兼容 `succeeded`、`SUCCESS`、`completed` 等状态；收到有效 `video_url` 即进入下一制作步骤。
- 区分参数错误、权限错误、可信人像未授权、安全审核、超时和网络重置。

### 方舟可信人像

真人参考素材需要在火山方舟完成本人授权并取得 Asset ID。将 Asset ID 填入角色资产，标记为“已授权”后，漫镜会通过 `asset://<asset-id>` 引用，不再把真人素材当普通图片提交。

## 模型与本地能力

- 火山方舟 Seedance 视频。
- OpenAI 兼容文本与多模态接口。
- Anthropic、Gemini、Pollinations。
- Agnes、自定义 Webhook 与自定义模型。
- 本地 2.5D 运镜、系统语音、本地桥接与可选 ComfyUI/MuseTalk 工作流。
- 每个用户使用自己的 API Key；Key 和项目数据默认保存在当前设备。

## 快速开始

1. 在 [Releases](https://github.com/Laity1m/manjing-desktop/releases/latest) 下载 Windows x64 安装包。
2. 安装并启动漫镜，在“模型中心”配置自己的模型与 API Key。
3. 在 AI 工作台输入故事、目标时长、画幅、清晰度、人物配音和背景音乐设置。
4. 在资产库确认 Canonical 角色、造型、场景、道具和声音档案。
5. 让 Agent 团队继续生成、检查并导入剪辑台。

## 安全与费用

- API Key 只发送给用户选择的模型服务，不用于分析或遥测。
- 项目、聊天、技能、记忆和资产默认保存在本地设备。
- 第三方模型可能收费；创建任务中断时请先在服务商控制台确认任务状态。
- 真人素材应取得本人授权，版权素材应由用户确认使用权限。
