# 漫镜 Manjing

<p align="center">
  <strong>从一句话到可播放成片的 AI 漫剧创作工作台</strong><br />
  剧本 · 角色 · 分镜 · 图片 · 视频 · 配音 · 剪辑 · Agent 团队
</p>

![漫镜品牌封面](README-media/漫镜视觉-01.png)

漫镜是一套面向 AI 漫剧、AI 短剧与视频创作者的 Windows 桌面工作环境。它把故事创作、角色设定、分镜编排、图像生成、动态视频、配音、素材管理和剪辑交付放进同一个项目，让创作过程真正连接起来，而不是在多个网站和工具之间反复搬运。

现在，漫镜正在进一步成为一支可以长期协作的 AI 制作团队：每个岗位都是可对话的 Agent，拥有自己的职责、技能与长期记忆，可以通过聊天、资料和实际工作逐步理解用户的创作习惯。

## 一支真正参与制作的 AI 团队

![漫镜多 AI 协作](README-media/漫镜视觉-02.png)

漫镜为完整制作流程设计了不同岗位。导演负责统筹风格与镜头语言，编剧负责剧情与对白，分镜 Agent 拆解场次，视频 Agent 调用生成模型，配音 Agent 管理角色声音，剪辑 Agent 完成节奏、转场和交付检查。

- 导演 Agent：创作方向、镜头调度、风格一致性
- 编剧 Agent：故事结构、人物弧光、对白与改写
- 分镜 Agent：景别、机位、运镜、时长与镜头节奏
- 视频 Agent：文生视频、图生视频和自定义模型调用
- 配音 Agent：角色声音、情绪表达与音轨规划
- 剪辑 Agent：素材编排、转场、节奏和成片检查

![会聊天的 AI 制作团队](README-media/漫镜-Agent团队.png)

每个岗位都拥有独立聊天空间。用户可以直接告诉 Agent 项目目标、修改意见和个人偏好，也可以把有效回复保存为记忆，把成功工作方法沉淀为技能，再将对话结果送入工作区继续生产。

## 技能、记忆与资料学习

![漫镜技能与长期记忆](README-media/漫镜-技能记忆.png)

Agent 学到的内容会进入自己的技能与记忆区，而不是消失在一次性聊天记录中。

- 长期记忆：保存用户偏好、项目规则和经过确认的工作经验
- 独立技能：每个 Agent 自动同步自己可以调用的专业能力
- 文件投喂：支持 Word、PDF、TXT、Markdown 和 Skill 文件入口
- 资料管理：查看 Agent 学习过的文件及其适用范围
- 学习记录：追踪技能和记忆的来源、修改与历史
- 用户可控：记忆支持查看、添加、编辑和删除

## 从故事到成片，一条完整工作流

![漫镜从故事到成片](README-media/漫镜视觉-03.png)

```text
故事与剧本
    ↓
角色设定与视觉风格
    ↓
分镜、景别、运镜与镜头时长
    ↓
图片、视频、配音与音乐生成
    ↓
素材进入资产库与项目
    ↓
画布编排与剪辑编辑
    ↓
预览、调整与成片导出
```

## 核心工作区域

### AI 工作台

从故事输入开始，组织角色、分镜、镜头素材和多个 AI 岗位。项目参数、生成结果与工作记录可以持续保存。

### AI 视频

支持文本、图片、视频和音频参考素材，配置画幅、时长、分辨率和模型，并将生成结果直接送入剪辑台。

### 画布

使用节点式生产画布组织剧本、角色、场景、图片、视频、音频和成片输出，适合复杂项目的可视化编排。

### 编辑器

管理视频、图片、音频和字幕素材，调整镜头顺序、速度、转场、音量和时间线，完成成片交付。

### 资产库与项目

统一管理生成素材、草稿、历史项目和成片结果，减少文件散落和重复生成。

### 模型中心

集中配置 API Key、模型 ID、服务地址和自定义模型。支持不同岗位使用不同模型，也支持本地与远程服务。

## 模型与接口

漫镜支持并持续扩展多种模型服务：

- 火山方舟 Seedance
- Agnes Video
- OpenAI 兼容接口
- Anthropic 兼容接口
- Gemini
- Pollinations
- 本地模型
- 自定义 Webhook

第三方模型的参数、限额和计费方式可能变化，请以对应服务商控制台和官方文档为准。

## Agnes Video 接入

漫镜同时支持在 AI 工作台的视频岗位和独立 AI 视频页面使用 Agnes Video。

推荐配置：

```text
接口地址：https://apihub.agnes-ai.com/v1
模型 ID：agnes-video-v2.0
鉴权方式：Bearer API Key
适配方式：自定义 Webhook
```

漫镜会按照 Agnes 异步任务流程创建视频任务，读取 `video_id`，并轮询生成结果；同时保留旧版任务查询兼容。

## 快速开始

1. 前往 [Releases](https://github.com/Laity1m/manjing-desktop/releases/latest) 下载最新版 Windows x64 安装包。
2. 完全退出并卸载旧版本，避免旧安装目录或快捷方式继续启动旧程序。
3. 安装后从开始菜单打开漫镜。
4. 在模型中心或对应工作区配置所需模型服务。
5. 创建项目，从 Agent 对话、AI 工作台或 AI 视频开始创作。

## 数据与隐私

- 项目与创作数据默认保存在本地环境。
- API Key 仅用于用户主动配置的模型服务。
- 漫镜不会把用户 Key 提交到公开仓库。
- 文件投喂、Agent 记忆和技能内容由用户控制和管理。
- 第三方模型可能产生费用，请确认服务商规则后使用。
