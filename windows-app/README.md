# 漫镜 Windows 桌面版

这是漫镜 AI 漫剧工作室的 Windows 客户端。它不是网页快捷方式，而是带独立窗口、页面导航、网络状态、下载反馈和欢迎视觉页的桌面软件。

## 直接使用

双击 `漫镜-Windows-1.0.0-x64.exe` 即可运行，无需安装。AI 生成能力需要联网，并需要按所选模型填写对应 API Key；Key 只保存在当前应用的本地浏览数据中。

## 页面

- 首页：查看完整制作流程。
- AI 工作台：编剧、导演、分镜、生图、视频、配音和 AI 剪辑。
- 专业剪辑台：导入 AI 工程后继续人工精剪并导出。
- 模型与 Key：查看接入教程并配置自定义模型。
- 项目与资产：管理保存在当前设备中的项目。

## 快捷键

- `Ctrl + 1`～`Ctrl + 5`：切换首页、工作台、剪辑台、模型和项目页。
- `Ctrl + R`：刷新当前页面。
- `Esc`：关闭欢迎视觉页。
