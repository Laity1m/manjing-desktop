# 漫镜 Windows 独立安装版 1.3.8

这一版已经完全移除旧桌面外壳和 `iframe` 桥接。Windows 主窗口直接运行安装包内置的漫镜应用，使用 `manjing://app` 内部协议读取页面、脚本和素材；不启动本地网页服务器，也不访问漫镜线上网站，更不需要登录 GPT。

## 安装

1. 双击 `漫镜-独立安装版-1.3.8-x64.exe`。
2. 选择安装目录，并按提示完成安装。
3. 从桌面或开始菜单打开“漫镜”。

如果已经安装旧版，可以直接运行 1.3.8 安装程序覆盖升级。安装程序会创建桌面快捷方式和开始菜单入口。当前版本尚未购买商业代码签名证书，因此 Windows 首次运行可能显示“未知发布者”；确认文件来自本文件夹后，可选择“更多信息”继续安装。

1.3.8 将所有软件内部链接交由 Windows 独立版主进程切换，不再让当前页面自己执行整页跳转。首页、工作台、自主视频、画布、剪辑台、资产库、模型和项目资产可连续切换；页面切换时显示轻量状态提示，当前页面未完成的界面任务不会锁死下一页。安装包增加八页面循环跳转自检。

1.3.7 修复模型删除、切换模型后整个平台按钮无法点击的问题。所有删除操作不再使用可能躲到 Electron 主窗口后方的同步系统弹窗，改为页面内二次确认；模型配置读写增加 6 秒自动解锁，本机文件操作增加 4 秒保护，即使磁盘或安全软件暂时占用设置文件也不会无限卡住。首页、顶部导航和剪辑台跳转改为独立版稳定直载，避免客户端路由悬停。Seedance 默认模型同步更新为 `doubao-seedance-1-5-pro-251215`。

1.3.6 内置火山引擎官方 Node.js SDK 1.36.2，并在独立版启动自检中确认 SDK 和签名器可以真实加载，用户无需另外安装或升级 SDK。Seedance/即梦视频生成仍按火山方舟官方接口使用 `ARK_API_KEY`，安装 SDK 不会替代模型开通、额度与密钥权限。

工作台新增“已有内容直接导入”：可导入剧本、完整分镜、角色图、场景图、视频和配音，AI 会锁定已有内容并只补齐缺少环节。新增独立持久化资产库，可分类保存图片、视频和音频，跨项目选择后直接送入工作台复用。

1.3.5 把 Seedance 创建、断点查询和成片下载切换为 Windows 独立版专用本机通道；查询会自动重试，视频会先完整缓存再交给界面。即使下载流中途断开，任务编号和已有素材也会保留，不再直接显示原始 `Failed to fetch`。

1.3.4 将人物资产与分镜关键帧彻底分开：人物固定生成 16:9 横版浅灰无缝影棚四视图设定表，包含左侧正面面部大特写以及正面、侧面、背面全身，严格锁定面部、发型、服装、饰品、鞋袜和身体比例；分镜图仍严格跟随用户选择的成片规格。旧工程点击“重新运行生图 AI”时会自动升级旧版人物设定图，同时保留已完成的分镜素材。

1.3.3 修复 Seedance 视频岗位重跑时只显示 `Failed to fetch` 的问题：创建、查询和下载阶段现在有分级重连与中文错误；未完成任务编号会保存在本机，网络中断后再次重跑会继续查询原任务，不重复创建和扣费。接口改为发送当前官方任务字段，不要求额外安装火山引擎 SDK。同时统一生图与视频关键帧规格：竖屏为 720×1280，横屏为 1280×720；受限模型返回的其他尺寸会在本机居中裁切适配后再传给视频 AI。

1.3.2 把“一键漫剧自动配音”提升为创作设置区顶部的独立醒目开关。它会真实控制普通漫剧流程、LibTV 一键漫剧提示和最终合成：关闭后跳过分角色配音并不再把已有对白音轨混入重新导出的成片；设置会保存在本机。

1.3.1 为自主视频生成新增可持久化的“生成视频配音”开关，并提供语言、人声风格和台词/旁白输入。Pollinations 会收到原生 `audio` 参数，Seedance 会收到音画联合生成要求，通用 Webhook 会收到结构化 `voiceover` 配置；关闭时明确请求静音视频。

1.3.0 新增完全独立的“自主 AI 视频”页面，可使用纯文字生成，也可上传图片、视频、音频作为全能参考，并通过 `@图片1`、`@视频1`、`@音频1` 精确引用。Seedance 2.0 与通用 Webhook 支持多模态素材组合，低能力模型会明确降级，不会假装使用未发送的参考素材。生成结果自动保存在本机项目库，可下载或一键导入剪辑台。

1.3.0 同时重做项目恢复：工作台剧本、分镜、进度与日志会跨页面保存；项目资产新增独立详情页，先读取轻量索引再由剪辑台逐项恢复媒体；“制作中”项目会回到原工作台，“新建同类作品”会创建新会话，避免旧工程一起加载造成卡死。

1.2.7 新增 16 种漫剧视觉风格与统一预览库，重点加入电影写实、都市生活写实、古装剧写实和港风复古。写实模式会贯穿角色设定、分镜生图和图生视频提示词，不再被旧版的“动画线稿”固定后缀覆盖；同时补充美式漫画、3D 动画、黑白漫画、黏土定格、油画奇幻、暗黑奇幻和治愈插画等风格。

剪辑台新增 `MPT 开源自动成片`：在本机启动 MoneyPrinterTurbo 与漫镜桥接后，可把当前时间线的图片和视频逐个上传到官方任务 API，查看真实剪辑进度，并把自动拼接、配音、字幕与 FFmpeg 压制后的成片导回漫镜。原始可编辑时间线不会被覆盖，任务可以停止等待，完成成片会继续写入本机历史。

开源节点中心新增 Microsoft VibeVoice Realtime 0.5B 实验配音节点，桥接服务会把官方 WebSocket PCM 流封装为 24 kHz WAV。该模型当前主要适合英文单角色流式配音，中文多角色仍推荐 CosyVoice；VibeVoice-ASR 提供可选健康检查，不会伪装兼容未经确认的第三方接口。

1.2.6 修复 OpenAI 兼容生图接口偶发返回 503、连接重置后立即中断整条制作流程的问题。生图请求和生成图片下载现在会对 408、429、502、503、504 等临时故障最多尝试 3 次，并遵守服务商返回的 `Retry-After`；密钥错误、地址错误等非临时故障不会重复请求。连续重试仍失败时，错误会明确说明服务商暂时不可用，已生成的剧本、分镜和图片仍会保留，可直接重新运行生图岗位。

1.2.5 重点修复 AI 作品导入剪辑台后卡死、保存工程一直转圈和“导入剪辑”闪退的问题。媒体现在逐个写入本机素材库，自动复用相同素材，前台保存不再等待清理任务；读取和写入会等待完整的 IndexedDB 事务结束，避免隐藏窗口中的事务互相排队。工作台和剪辑台的批量素材列表改用静态封面，不再为每段视频同时启动播放器，显著降低大工程的内存和解码压力。

导入剪辑台、保存工程、模型写入、项目恢复/删除和单镜头重做都增加了立即生效的重复点击保护与明确进度。编辑器视频导出和工作台成片合成均可中途停止，并会保留时间线和已有素材。编辑器中的“保存工程”只做可靠的本机持久化，不再同时触发可能阻塞窗口的系统下载。

六个 AI 岗位继续提供独立的“再运行/重新运行”按钮。接口超时后会保留已经完成的剧本、分镜和媒体，只补跑失败或缺失的当前岗位任务；错误提示也会准确标出实际超时的岗位。全部素材已完成时，仍可主动重做当前选中的镜头、配音或剪辑方案。

“保存此岗位 API 并立即应用”现在会同时新增或更新“我的模型”，更改模型 ID 后不再保留旧数据。用户添加的模型都能单独删除；若删除当前岗位正在使用的模型，该岗位会安全切回免费默认模型。内置推荐模型不会出现删除按钮。生图岗位继续支持 OpenAI 兼容 `/images/generations`，剪辑岗位可使用 GPT/OpenAI 兼容、Claude、Gemini、Pollinations 或 Webhook 模型生成结构化剪辑方案。

API、Key、岗位模型、工作台参数会写入 Windows 用户应用数据目录，重启或覆盖升级后自动恢复。剪辑工程、原始素材和导出成片保存到本机 IndexedDB 项目库，可在“项目与资产”页面恢复到剪辑台继续编辑。兼容接口由独立版在本机发起请求，不经过漫镜网站服务器，也不受浏览器跨域限制。

## 独立运行说明

- 首页、AI 工作台、剪辑台、模型设置、项目页面和三张漫镜视觉素材都保存在安装目录中。
- 程序会在后台完成内置资源自检，准备完成后才显示主窗口，不再出现网页桥接加载页。
- 不联网也能打开软件、浏览页面、使用本地项目和剪辑功能。
- 调用语言、图片、视频或配音模型时仍需联网，并填写相应服务商的 API Key。
- API Key 与项目数据保存在本机应用数据中；卸载时默认保留，方便重装后继续使用。

## 主要页面

- 首页：查看完整 AI 漫剧制作流程。
- AI 工作台：编剧、导演、分镜、生图、视频、配音和 AI 剪辑协作。
- 专业剪辑台：导入 AI 工程，继续人工精剪并导出。
- 模型与 Key：配置推荐模型或自定义模型。
- 项目与资产：管理剧本、分镜、图片、音频和视频资产。
